# simpleImageLibrary
Simple image organization using bash and basic file system tricks

This application strives to be a light-weight image library management framework
utilizing open source tooling with a command line interface.

# Feature Roadmap

* Maintain one or more libraries, each fully contained within a folder structure
* Add images to library via URL or local file path
* Operate directly from command line, or by parsing manifest files
* Recognize duplicate images via fingerprinting
* Optimize image disk size via format change (eg PNG -> JPG) or quality change
  (JPG quality reduction)
* Capture basic image metadata (source, date)
* Organize images via keyword
* Maintain technical simplicity
